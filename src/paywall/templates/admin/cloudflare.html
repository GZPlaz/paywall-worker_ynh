Lock down the origin (recommended)

The Worker only protects traffic that goes through Cloudflare. Someone who knows your server's IP could bypass it. Every request the Worker forwards carries an X-Paywall-Origin-Key header; reject requests without it on the origin. For an app hosted on YunoHost, add this to /etc/nginx/conf.d/<protected domain>.d/<app>.conf inside the location block:

if ($http_x_paywall_origin_key != "{{ cfg.origin_secret }}") { return 403; }
