Close the back door

The Worker only sees traffic that goes through Cloudflare. Anyone who knows your server's address could skip it. Every request the Worker forwards carries an X-Paywall-Origin-Key header, so make the origin refuse requests without it. For an app on YunoHost, put this line in a file included from the app's nginx location block, so that upgrades do not overwrite it:

if ($http_x_paywall_origin_key != "{{ cfg.origin_secret }}") { return 403; }
